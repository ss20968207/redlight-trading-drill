# 指標交易訓練所

練習「紅綠燈」日內偏見＋3+1／馬刺進場訊號背後的判斷力。10 題，每題顯示連續兩根K棒，玩家要判斷第三根會是陽K還是陰K——純粹的對錯判斷，沒有本金、沒有盈虧比。

這是一個獨立的靜態網站，沒有建置流程，也不依賴任何後端或資料庫——`index.html` 一個檔案就是整個遊戲。刻意跟主要的交易紀錄／儀表板專案（tammy-ai）分開部署，因為那個專案的 `/journal` 沒有登入機制，不適合把公開流量導過去。

## 部署

在 Vercel 匯入這個 repo，Framework Preset 選 **Other**（或讓它自動偵測靜態站），不用任何額外設定，直接 Deploy 即可。

## 修改遊戲內容

所有邏輯（題目產生規則、勝率、盈虧計算、文案）都在 `index.html` 裡的一個 `<script>` 區塊，沒有分檔案、沒有 build step——改完存檔，git push 上去，Vercel 會自動重新部署。
